# Smart Refrigerator UI Prototype – UI/UX Design

2026

This project is a UI/UX design concept for a smart refrigerator interface, created as part of a course on web publishing and usability.

The task was to design a user interface for a 10-inch touchscreen placed on a refrigerator door. I focused on creating something that feels simple, clear, and actually useful in everyday life.

> This is a concept design and interactive prototype created in Figma.


## Overview

The idea behind this project was to explore how a smart refrigerator could help users keep track of their food more easily and reduce food waste.

I wanted the interface to feel calm and easy to understand at a glance, even in busy everyday situations.

The design includes:
- a home view with key information  
- camera views inside and outside the fridge  
- food tracking with freshness indicators  
- notifications about important events

## Use Case – Checking What’s in the Fridge

Goal:  
The user wants to quickly see what food is available.

Steps:
1. The user approaches the fridge  
2. The screen shows basic information  
3. The user opens the home screen  
4. They tap into the camera view  
5. The system shows the items inside with status indicators  

Outcome:  
The user understands what’s inside the fridge without opening it and can decide what to use.


## User Path

The main flow is designed to be simple:

Screensaver → Home → Camera View → Item Details

The goal was to make each step feel obvious and easy, without needing to think too much.


## Usability & Accessibility

While designing, I paid attention to usability principles like:

- showing important information clearly  
- keeping layouts consistent  
- making things easy to recognize instead of remember  
- giving helpful notifications before problems happen  

I also considered accessibility by using:
- clear typography  
- good contrast  
- simple and touch-friendly layouts
